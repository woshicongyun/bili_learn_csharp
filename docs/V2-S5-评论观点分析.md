
# V2-S5 任务书：评论区高赞观点分析功能

## 任务概述
在Learn流程中增加拉取评论区高赞前10条，加入LLM分析输出评论观点，并保存持久化的新功能。

## 用户故事
作为用户，我希望B站视频学习时能自动分析热门评论观点，这样我可以了解其他观众的关注点和讨论方向。

## 技术方案

```csharp
{
    public string Bvid { get; set; } = "";
    public string Message { get; set; } = "";

    public string Author { get; set; } = "";

```

#### 2. 修改 KnowledgeBaseService.cs ✅
新增字段：
- `public string? CommentInsights { get; set; }`
- `public List<CommentItem>? Comments { get; set; }`

### 二、API服务变更

#### BilibiliApiService.cs 新增方法 ✅
```csharp
public async Task<List<CommentItem>> GetTopCommentsAsync(
    string bvid, 
    int limit = 10, 
    CancellationToken ct = default)
```
- API端点: `https://api.bilibili.com/x/v2/reply?type=1&oid={aid}&sort=1&ps={limit}`
- 解析data.replies数组，提取member.uname、content.message、like

### 三、AnalyzeService 变更 ✅

#### 在ProcessAsync中新增评论获取步骤
```csharp
// V2-S5: 获取热门评论
await _progressReporter.ReportAsync("💬 获取热门评论...", ProgressLevel.LogAndPush);
try
{
    var comments = await _biliApi.GetTopCommentsAsync(ctx.Bvid, limit: 10, ct: cancellationToken);
    ctx.Comments = comments;
    await _progressReporter.ReportAsync($"✅ 获取评论成功: {comments.Count}条", ProgressLevel.LogAndPush);
}
catch (Exception ex)
{
    _logger.LogWarning(ex, "获取评论失败，跳过评论分析");
    ctx.Comments = new List<CommentItem>();
}
```

## 关键设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 评论拉取时机 | 字幕后、LLM整合前 | 避免阻塞音视频下载 |
| 并行处理 | 与ASR/视觉并行 | 减少总耗时 |
| 容错处理 | 失败不阻塞主流程 | 评论为辅助信息 |
| 持久化策略 | 单独存储，按BV号查询 | 便于后续查询历史评论 |
| 返回类型 | List<CommentItem> | 符合服务层规范 |
